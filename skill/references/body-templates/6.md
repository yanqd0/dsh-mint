# T6 plan 执行方案

**用途**：记录执行方案 plan。

```markdown
## 目标 <一句>
## 拆解
- 每 phase 一行
## 并行批次
- 并行批次：#N、#M（文件不相交）
- 依赖批次：#K（依赖 #N）
- 串行独占：CHANGELOG.md（#J）
## 验收
- 每项一行
```

按 phase 拆解，验收可验证。
`## 并行批次` 段名固定，判据见 `parallel-exec.md` §1；**无并行机会也要写「单批串行」+ 一句理由**（例：三条 issue 都改同一文件）。
**要点**：拆解/验收用纯 `- ` 列表，**禁止 `- [ ]` checkbox**——agent 不二次改 body，checkbox 会永远显未完成。
